# Genesis root candidate G-R11: source-description information

2026-10-02. Public core promptly discarded; no main proof and no audit. This was a brief candidate preflight for a tool based on the information in the two defining procedures, rather than arithmetic approximation or functional monodromy.

## Exact scope and failure

For every fixed total computable binary sequence alpha, its length-n prefix satisfies C(alpha[1:n] | n)<=c_alpha: one fixed program computes the prefix when n is supplied. Its unconditional prefix complexity is at most C(n)+O_alpha(1), and its normalized asymptotic program-size information is zero. The same holds for a fixed pair of computable sequences, even when one comes from a factorial law and the other from a circular law: a fixed program computes both from n. Conditional complexity of either prefix given the other prefix AND n is bounded as well, because the program can ignore the other prefix.

These elementary facts do not prevent computable digit sequences from being normal in a base. Statistical frequency and algorithmic program-size randomness are different predicates. They also do not say that every proposed complexity measure, time bound or eventual periodicity test is equivalent or unusable.

For the actual e and pi, unconditional total rational Cauchy-name programs are explicit. The factorial partial sum E_N=sum_(j=0)^N1/j! has positive error at most2/(N+1)! for N>=1. Machin's identity pi=16 atan(1/5)-4 atan(1/239) and the alternating odd-power sums give effective rational error bounds for pi. Computing enough terms gives total rational names for e,pi,and S=e+pi to any specified precision without assuming whether S is rational. The joint approximate transcript therefore has constant conditional description overhead given the requested precision. Arithmetic cancellation cannot be excluded by declaring these two computable transcripts algorithmically independent in the unbounded Kolmogorov sense.

Canonical radix digits require care at exact grid boundaries. Uniform conversion of arbitrary Cauchy names to chosen digits is not assumed. For a fixed computable real, its canonical digit sequence is nevertheless computable nonuniformly: if it is a grid rational, a finite rational specification gives a digit program; otherwise increasing certified precision eventually decides each finite prefix. This case distinction is an existence argument, not an algorithm deciding which case S belongs to. The Cauchy-name failure above is already unconditional and does not depend on this distinction.

A fixed absolute program-length cutoff cannot separate all rationals from computable irrationals either. Rational numbers can encode arbitrarily incompressible finite prefixes, while a computable irrational may have a short defining program. Additive machine constants must not be promoted into intrinsic arithmetic obstructions.
