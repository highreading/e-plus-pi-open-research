# Primary-source gate for actual seeded contact correlation

The current A3turn2 gives explicit paid contact directions and a source-specific
B_j support identity, while the subfactorial large-prime correlation is open.
The parent and A4 separately decide the displayed universal rational gauge;
this route is closed and should not receive more guessed-denominator searches.
Archive searches of source Markdown for the primary identifier and author below
found no match. This is a narrow retrieval statement, not exhaustive novelty.

Zheng Xiao, *Greatest common divisors for polynomials in almost units and
applications to linear recurrence sequences*, arXiv:2110.01751v3 (2023):
https://arxiv.org/abs/2110.01751
https://arxiv.org/pdf/2110.01751

The parent read the abstract, almost-S-unit definition and introductory theorem
statements. The results bound polynomial gcd heights at almost-S-unit points
outside exceptional algebraic sets and apply to suitable algebraic linear
recurrences. They do not automatically apply to the present rational-coefficient
shift system. A proposed application must prove the required point description,
small height outside a fixed finite S, coprimality and exceptional-set avoidance.
For an unremoved n!, height outside any fixed finite prime set is
log(n!)-O(n), so the required small outside-S ratio cannot simply be assumed.
No applicability or new general gcd theorem is claimed.

The research target is a valid theorem for the actual seeded contact values,
or a rigorously delimited obstruction and alternative source identity. Generic
resultants with a free transverse coordinate cannot close that target.
