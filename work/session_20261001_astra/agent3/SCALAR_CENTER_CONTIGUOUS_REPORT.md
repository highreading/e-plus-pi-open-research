# Scalar-center contiguous report

Original author research, not independently audited. The main scalar draft was read in full. No old calculation, plateau proof, HP scan, or within-index dyadic/ternary analysis was repeated.

Write U_n=N_n/(n!)^2=Qcal_n+2^n Acal_n/(n!)^2. A constant-term derivation gives the exact exponential forcing tau_n. It is generated by a three-coordinate diagonal-coefficient recurrence, two delayed scalar coefficients, and one forcing value: six stored rational coordinates, with no exceptional nonnegative index.

For n>=1 the requested integers satisfy

    N_(n+1)=2(2n+1)(n+1)N_n+4n^3(n+1)N_(n-1)+T_n,
    Z_(n+1)=2(2n+1)(n+1)Z_n+4n^3(n+1)Z_(n-1),
    T_n=(n+1)(n!)^2 tau_n.

The n=0 step is initialized separately by N_0=Z_0=1, N_1=14, Z_1=2. The second-kind contribution is retained in these initial values.

The adjacent determinant factors exactly as

    N_(n+1)Z_n-N_nZ_(n+1)=(n!)^2 D_n,
    D_0=12,
    D_n=-4n(n+1)D_(n-1)+T_nP_n.

This removes the automatic common factorial before integer arithmetic. Dividing out both original normalization factorials gives the rational, factorial-free expression

    W_n=(-4)^n/(n+1)
          [12+sum_(k=1)^n P_k tau_k/(-4)^k],
    c_(n+1)-c_n=W_n/(P_nP_(n+1)).

The constant 12 consists of second-kind contribution 8 and exponential contribution 4. A factorial displayed outside this rational sum is not asserted to be an extra integer divisor.

For g_n=gcd(Z_n,|N_n|), the exact restriction is

    g_n g_(n+1) divides (n!)^2 D_n.

The note spells out its primewise consequence for simultaneous reduction. It also strengthens the adjacent denominator-product bound using shared reduced factors. With h_n=gcd(q_n,q_(n+1)), rational separation gives

    q_n q_(n+1)/h_n >= C^(-1)(1+sqrt(2))^(2n)

eventually, for an explicit constant C supplied in the note. Accepting the main draft's exact 5-adic law gives 5^(2v_5(n!)) dividing h_n and therefore

    log q_n+log q_(n+1)
      >= [2log(1+sqrt(2))+(log 5)/2]n-O(log n).

This improves the earlier adjacent-product exponent by (log 5)/2. It uses the main draft's author-scope alternating error and 5-adic result without replay; it is not an independently reviewed result or an upper denominator bound.

Applying the homogeneous numerator/denominator operator to the complete linear forms eliminates the coefficient of e+pi and leaves only -T_n. The note explicitly stops there: this is not an improved linear form.
