UNREVIEWED COROLLARY: a logarithmic search interval for the optimal block cutoff.

Fix an odd prime p and precision d≥1. Write g(k)=k−v_p(k!), with g(0)=0. The audited individual-summand theorem identifies the optimal block cutoff as J=1+max{k≥0:g(k)<d}. Its closed-form sufficient cutoff is K=max(1,ceil((p−1)(d−1)/(p−2))). The following refinement concerns this scalar cutoff problem only.

For d=1, J=K=1. For d≥2, put A=p−2, B=(p−1)(d−1), let L be the number of base-p digits of K−1, and define H=max(0,floor((B−(p−1)L)/A)). Then

H+1≤J≤K,
K−H≤ceil((p−1)L/A)+1.

Consequently J can be found by testing g(k)<d only for H≤k<K, and 0≤K−J≤ceil((p−1)L/A)=O_p(log d).

Proof. Legendre’s formula gives (p−1)g(k)=Ak+s_p(k), where s_p is the base-p digit sum. For k≥K, Ak≥B and s_p(k)≥1, so g(k)>d−1. Thus every bad index is below K. Also H≤K−1. If H>0, its digit sum is at most (p−1)L and the definition of H gives AH+(p−1)L≤B; hence g(H)≤d−1. If H=0, this conclusion follows from g(0)=0. Therefore the last bad index lies in [H,K−1]. Finally, writing C=(p−1)L, the elementary ceiling/floor inequality ceil(B/A)−floor((B−C)/A)≤ceil(C/A)+1 proves the interval-width bound; replacing a negative lower endpoint by zero only shortens the interval. This argument assumes no monotonicity of g.
