The retained source resolves the endpoint sign and unit conventions. It computes ratio=X/D=A_raw(1)/B_raw(1), using the common scale gamma=(-1)^n/[4(n+1)^3(n!)^4]. With the remainder convention R=A+B exp(z)+C F(z), F(1)=pi, and matched endpoints B(1)=C(1), the corresponding approximation to e+pi is -X/D. Both signs have the same positive reduced denominator.

The source defines Z=X/[f(n+1)], f=2^n/(n!)². Its recorded units are 5^(-v_5(Z))Z and 5^(-v_5(D))D modulo 625. The D unit therefore uses division by a power of five, rather than division by n+1.

For zero, both valuation and unit functions return None, serialized as null; valuation null denotes infinity. If D=0, the ratio and its denominator valuation are undefined and also represented by null. The source alone supplies no numerical D-unit entries.
