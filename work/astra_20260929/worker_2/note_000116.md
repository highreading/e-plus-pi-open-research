Unreviewed supplementary derivation. Work along an unbounded index set where the same positive reduced denominator q_n satisfies v_3(q_n)≥2v_3(n!), and the normalized error satisfies |e_n|=Cρ^(−2n)(1+o(1)), with ρ=1+√2 and C>0. For the audited b=2 normalization, C=4π/ρ³.

Write F_p(n)=v_p(n!) and let s_p(n) be the base-p digit sum. For this supplement define the nonnegative deficiency L_n=max(0,2F_5(n)−v_5(q_n)), the excess valuations a_n=v_3(q_n)−2F_3(n)≥0 and b_n=max(0,v_5(q_n)−2F_5(n)), and the positive integer u_n=q_n/[3^{v_3(q_n)}5^{v_5(q_n)}]. Set H_n=3^{a_n}5^{b_n}u_n≥1. These definitions give the exact identity
q_n=3^{2F_3(n)}5^{2F_5(n)−L_n}H_n.

Legendre's formula therefore yields
log(q_n|e_n|)=log C+δn−s_3(n)log3−[s_5(n)/2]log5−L_n log5+log H_n+o(1),
where δ=log(3√5)−2logρ>0.

Consequently, shrinking is equivalent, under these hypotheses, to
L_n log5−δn+s_3(n)log3+[s_5(n)/2]log5−log H_n → +∞.
This is an exact reformulation, not an estimate for any of its arithmetic terms. Dropping log H_n≥0 gives the stronger digit-sensitive necessary condition
L_n log5−δn+s_3(n)log3+[s_5(n)/2]log5 → +∞.

For n≥1, the elementary digit bounds give
s_3(n)log3+[s_5(n)/2]log5 ≤4log n+log225.
Thus shrinking necessarily implies L_n log5−δn+4log n→+∞, and hence liminf L_n/n≥δ/log5. The inequality direction is essential: an upper bound for the digit penalty weakens the necessary condition.

The factor H_n contains every excess valuation at 3 and 5 and every other prime factor of q_n. Even satisfying the necessary loss condition leaves its growth uncontrolled. An argument claiming sufficiency would have to control log H_n as well. This supplement uses only the explicit valuation and error hypotheses; it supplies no such control and no conclusion about the rationality of e+pi.
