Suppose the source's exact reference identities and determinant estimates hold. They give E_n:=R(1)/Y=(-1)^nκ^b ε_n(1+η_n), with ε_n>0 and η_n→0. Therefore E_n≠0 eventually. Writing X/Y=a_n/q_n in lowest terms produces the primitive coefficient form L_n=a_n+q_nθ, with gcd(a_n,q_n)=1. If θ=u/v with integers u,v and v>0, then vL_n=va_n+uq_n∈Z\{0} eventually, so |L_n|≥1/v. Any unbounded subsequence with q_n ε_n→0 contradicts this lower bound. In fact |L_n|/(q_n ε_n)→κ^b, so q_n ε_n→0 is exactly equivalent to shrinking forms on such a subsequence.

The cited reference rate log ε_n=−cn+o(n), c=2log(1+√2), implies log|L_n|=log q_n−cn+o(n), without any restriction on how large q_n is: multiplication by q_n introduces no additional analytic error. For an infinite set S of indices, limsup_{n∈S}log(q_n)/n<c suffices for exponential shrinkage along S. A global liminf strictly below c suffices after choosing a subsequence. Conversely, liminf_{n∈S}log(q_n)/n>c forces |L_n|→∞ along S. If shrinking forms exist along S then limsup_{n∈S}log(q_n)/n≤c, but this non-strict inequality is not sufficient.

A stronger upper bound on ε_n could change this conclusion, but must be proved or read explicitly.
