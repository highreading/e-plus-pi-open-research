Unreviewed scope check. Put rho=1+sqrt(2), C=4pi/rho^3, and choose the rational target theta=6. For n>=1 set Q_n=3^n 5^ceil(n/2). Choose an integer k_n congruent to 1 modulo 15 nearest to t_n=(-1)^(n+1) C Q_n rho^(-2n), and set P_n=6Q_n+k_n. Then |k_n-t_n|<=15/2. Since Q_n has only the prime factors 3 and 5 and P_n is congruent to 1 modulo 15, gcd(P_n,Q_n)=1: Q_n is the actual positive reduced denominator.

Consequently theta-P_n/Q_n=(-1)^n C rho^(-2n)+O(Q_n^(-1)). Moreover Q_n>=(3sqrt(5))^n. The base T=3sqrt(5)/rho^2 exceeds one exactly: 3sqrt(5)>6, whereas rho^2=3+2sqrt(2)<6. Hence Q_n rho^(-2n)>=T^n tends to infinity, making the rounding error negligible relative to rho^(-2n). Thus theta-P_n/Q_n=(-1)^n C rho^(-2n)(1+o(1)), while |Q_n theta-P_n| tends to infinity. The denominator bound Q_n>=(3sqrt(5))^n/(9n^4) holds in particular on every multiple of five n>=5.
