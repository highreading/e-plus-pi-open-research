Unreviewed conditional synthesis. Let p_n/q_n be reduced rational approximants to a real number α, with q_n>0, and write E_n=α−p_n/q_n. Suppose, along an unbounded index set S, that |E_n|=K(1+√2)^(−2n)(1+o(1)), where K>0, and that v_3(q_n)≥2v_3(n!) and v_5(q_n)≥2v_5(n!). Then q_n|E_n| tends to infinity along S.

Indeed, writing s_p(n) for the base-p digit sum, Legendre's formula gives 2v_3(n!)=n−s_3(n) and 2v_5(n!)=(n−s_5(n))/2. Consequently,
q_n≥(3√5)^n/[3^{s_3(n)}5^{s_5(n)/2}].
For every integer n≥1, the elementary digit bounds imply 3^{s_3(n)}≤9n² and 5^{s_5(n)/2}≤25n². For sufficiently large n in S, therefore,

The exponential base exceeds one: 3√5>6>3+2√2=(1+√2)². This proves the assertion without a numerical comparison.
