Unreviewed supplementary derivation. For n≥3 divisible by 3, write q_n=3^{n−s_3(n)}r_n with r_n a positive integer coprime to 3, using the published ternary theorem and Legendre’s formula. Put T_n=3^{n−s_3(n)}, the exact ternary part of q_n.

If k=floor(log_3 n), the base-3 expansion has k+1 digits and its last digit is zero. Consequently 1≤s_3(n)≤2k, giving

3^n/n^2 ≤ 3^{n−2k} ≤ T_n ≤ 3^{n−1}.

In particular, T_n^{1/n}→3 along the stated progression. The polynomial exponent 2 in a uniform lower estimate for T_n cannot be decreased: at n_k=3(3^k−1), the expansion consists of k digits equal to 2 followed by zero, so s_3(n_k)=2k. For every real γ<2,

T_{n_k}/(3^{n_k}/n_k^γ)=n_k^γ/3^{2k}→0.

This sharpness concerns only T_n; it does not establish sharpness of a lower bound for q_n, because r_n is unknown.
