Unreviewed supplementary derivation; conditional arithmetic statement only.

Write s_p(x) for the base-p digit sum of a nonnegative integer x. If s_p(x)=(p−1)k+r with 0≤r<p−1, then
x+1≥(r+1)p^k.
Indeed, among integers with a fixed digit sum, moving a digit unit from a higher position to an unfilled lower position decreases the integer. The minimum therefore has k trailing digits p−1 and leading digit r. Equality holds exactly at x=(r+1)p^k−1.

Fix n≥6 with n≡1 mod5 and put m=(n−1)/5. Then s_5(n)=s_5(m)+1, while s_3(n)≡n mod2 and s_5(m)≡m mod2. Define
F=3^{s_3(n)}5^{s_5(n)/2}, T=(n+1)^2(n+4)^2.

If n is odd, s_3(n) is odd, so the digit minimum gives
3^{s_3(n)}≤3(n+1)^2/4.
For every m, the same lemma gives 5^{s_5(m)/2}≤(m+1)^2. Consequently
F≤3√5 T/100=3T/(20√5).
Equality would require n=2·3^k−1 and m=5^l−1. Since n≥6, k≥1. But then n+4=2·3^k+3=5^{l+1}, impossible modulo three. Thus this bound is strict.

If n is even, 3^{s_3(n)}≤(n+1)^2, and m is odd. Write s_5(m)=4l+r, where r is either 1 or 3. The digit minimum gives
5^{s_5(m)/2}/(m+1)^2≤5^{r/2}/(r+1)^2≤5√5/16.
The last maximum occurs at r=3. Hence F≤T/16. Equality would require n=3^k−1 and m=4·5^l−1. Here k≥1, and n+4=3^k+3=4·5^{l+1}, again impossible modulo three. This bound is also strict.

Now assume q is a positive integer with v_3(q)≥2v_3(n!) and v_5(q)≥2v_5(n!). Legendre's formula yields
q≥3^{n−s_3(n)}5^{(n−s_5(n))/2}=(3√5)^n/F.
The two strict bounds for F give the stated constants 20√5/3 and 16. In particular, the uniform constant 20√5/3 is valid because 16>20√5/3.

This strengthens the earlier supplementary bound under the same explicit valuation hypotheses. It requires no analytic error estimate.
