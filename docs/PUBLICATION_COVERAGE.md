# Publication coverage and anonymity

This is a curated anonymous research release, separate from the private preservation archive. Research remains stopped. Preparing the release made no new model/API research requests and ran no mathematical experiments. It retrieved license documentation and performed file inventory, hashing, text extraction/classification, anonymization, structure and syntax checks.

## Source coverage

The consolidated source snapshot contains **110,191 regular files** and **8,982,879,941 logical bytes**, plus **129 recorded symlinks**. Every regular file in that snapshot was inventoried and streamed through SHA-256 hashing. File classification covers mathematical records, operational/history material, third-party dependencies, software/applications and literature context. This whole-file audit is not a claim that every vendor file, every PDF page or every mathematical argument was newly reviewed semantically.

The release selects research notes, complete mathematical AI reports, full proof and audit files, exact finite receipts and offline-oriented project code. Identical textual source bodies are consolidated with source aliases resolved in public navigation. Source-module copies needed for local imports are retained as real text files. No source symlinks are followed into the public release.

All 204 manuscript sources in the dated formal review register are available in full, with a fresh [scoped public review map](../reviews/LEGACY_SCOPED_REVIEWS.json). The seven embedded native-body reviews retain their scoped explanatory record. The latest stage preserves 100 complete reports, 76 actual saved coordinator notes and the explicit absence of 24 separate notes. No missing response or review was reconstructed. Many other historical notes remain unreviewed.

Six principal excluded families/regimes have complete proof dossiers, direct review links where an independent audit exists, and principal dependency files. Additional limited obstructions and finite refutations remain clearly distinguished. The release does not treat every filename containing “barrier” or “PASS” as a proved exclusion.

## Anonymization and omissions

Personal user identifiers, local home paths, machine/account/session metadata, email identifiers and credential-shaped values were screened. Known local credential values were checked privately; they were never used to call a model and are not included in publication receipts. Paths were mapped to public relative files where possible. Session identifiers and irrelevant account/transport fields were removed.

The release excludes raw API request/response transport containers, billing/balance evidence, credentials, application state, private conversations, author-profile screenshots, database files, copied Git history, application builds, vendor runtimes, private backups and binary archives. Third-party full papers and downloaded manuscript source trees are generally replaced by citations and primary links. Scholarly author names and public bibliographic URLs are retained for attribution.

Some historical links point to deliberately omitted operational files or old evidence locations. Those links have been rendered as annotated historical references rather than broken public file links. The original private bytes and detailed source-to-public mapping remain outside this package. This publication does not expose the private source inventory or its personal paths.

## Mathematical and mechanical checks

Literal LaTeX fragments in imported Markdown were first compared with the source after anonymization, with no changes. Publication then adapted outer math delimiters to GitHub inline `$` and display `$$` syntax, preserving every checked LaTeX expression body. This follows [GitHub’s mathematical-expression documentation](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions). Code examples were protected from delimiter conversion. **No expression-body changes remain.** Numeric/boolean payloads and structure were compared for **2059 imported JSON files**, excluding explicit operational metadata fields; **no unexpected numeric or boolean changes were found**. Generic mathematical fields such as endpoint, transport, model, mode and table headers were retained.

These checks protect transcription and data preservation. They do not verify theorems, establish source priority or certify every legacy program as safe or portable. Python files receive static syntax checks; archived mathematical code was not executed during publication preparation. Dependency availability, runtime behavior and each mathematical claim still require the scoped review described in the repository.

The release has a file manifest and a standalone validator for privacy patterns, JSON, Python syntax, local Markdown targets and hashes. It does not contact providers or run archived programs. Read [reproducing evidence](REPRODUCING.md) for its limits. GitHub account and commit metadata require separate care at actual publication; see [publishing](PUBLISHING.md).

## Pre-upload hardening

A second complete content scan before GitHub upload found historical Windows user-directory paths missed by the first path-pattern check. These were removed from two operational-history paragraphs, replaced by repository-relative resolution in 21 archived scripts, and mapped to repository-relative references in three JSON records. The 32 affected path occurrences included escaped JSON strings. Mathematical formula bodies and JSON mathematical data were unchanged. Windows paths and additional credential shapes are now covered by the validator. Three regenerated Finder metadata files were moved out of the public package. Only the independently inventoried, sanitized release files are eligible for the initial anonymous commit.
